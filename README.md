# Портфолио K-HAZ

Сайт-визитка моушн-дизайнера. Статические страницы, без базы данных и без сборщиков.

## Как устроено

- `content/works.json` — все тексты и список работ.
- `build.py` — собирает страницы из `works.json` в папку `docs/`.
- `docs/` — готовый сайт, его показывает GitHub Pages.
- `docs/css/site.css` — оформление.
- `docs/media/` — кадры и постеры (ролики лежат отдельно, по ссылкам).

## Как обновить

1. Поправить `content/works.json`.
2. Запустить `python3 build.py`.
3. Закоммитить и отправить изменения.

## Включить сайт

GitHub → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
